# Trabajo_Final_Integrador_Mauro_Ponce_TUPAD
Proyecto final para TUPAD: Sistema web de gestión logística, comercial e inventario para Pollito Casero. Digitaliza cargas, pesajes, repartos, ventas móviles, arqueos por vehículo, mermas y cuentas corrientes, con trazabilidad integral desde el galpón hasta la rendición del repartidor.
